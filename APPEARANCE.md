# Appearance and navigation

The profile at the bottom of the sidebar now contains **Appearance → Light / Dark**, Business profile, Account, Security, Brand studio, Reminders and Sign out. A profile button in the top bar keeps these controls available on small screens. The native disclosure supports keyboard access, outside-click dismissal and Escape. Settings and Documents have been removed from the main workspace navigation.

Light mode retains the current white/lavender design and remains the default. Dark styles restore the preceding charcoal TCS palette from the saved source snapshot, with a restrained increase of purple accents. New Excel review components receive matching dark surfaces. Theme preference is a non-sensitive, one-year, same-site browser cookie; the root server layout reads it before painting, so reloads and new tabs start in the saved mode. Other open tabs synchronise when focused. No account or financial data is stored in this preference. Public pages are now rendered dynamically to honour the cookie.

Invoice document previews and invoice output retain their own brand colours and white paper styling. Native form controls follow the selected interface mode. Print rules remain light. Reduced-motion and keyboard-focus styling are retained.

Documents appears as a dashboard card, opening `/reports/documents` in a new tab with an accessible new-tab label. Reports has Reports / Documents tabs. Tax overview, GST and financial-year screens link to this same document library in a new tab. The former `/documents` URL redirects to the new location. The library has filename/supplier/invoice search, review-status filtering and links to existing source reviews. It inherits the authenticated Reports layout and existing workspace-scoped vault API; it does not duplicate or move stored documents.

Verification on 5 October 2026: all 50 main-project tests passed, ESLint passed and the production build succeeded. Local HTTP checks confirmed light/dark server painting, safe fallback for an invalid preference and authentication protection on `/reports/documents`. Tests preserve prior invoice, tax and Excel workflows and cover preference validation, initial radio selection, settings placement, dashboard new-tab behaviour and the Reports view. No dependencies were added. No Git staging, committing, pushing or syncing was performed.
